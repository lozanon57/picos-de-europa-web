# Operación «Picos de Europa» — web de presentación

Sitio estático (GitHub Pages) para compartir el proyecto del **Reto Idonia · I Hackathon IABiomed**.

🔗 **Web:** https://lozanon57.github.io/picos-de-europa-web/

Equipo: Pablo Lozano Lominchar · Nieves Cubo · María Homero — HGU Gregorio Marañón.

## Contenido
- `index.html` — landing con problema, solución (3 fases), **demo interactiva** (sin backend),
  características (DICOM, OCR, email), arquitectura y documentos.
- `docs/` — resúmenes descargables: [Resumen del proyecto](docs/Resumen_Proyecto.docx) y
  [Resumen técnico](docs/Resumen_Tecnico.docx).
- `assets/` — imagen sintética de demostración y QR.

## Aviso
Prototipo **experimental**, no validado clínicamente. Todos los datos son **ficticios** (RGPD).
Este repositorio es público y **no contiene** código del backend, claves ni materiales del
patrocinador (que se mantienen en un repositorio privado aparte).
